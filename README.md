# 최소 성취수준 도우미

고교학점제의 과목 이수 기준(출석률 2/3, 공통과목은 학업성취율 40%)에 못 미칠 수 있는 학생을 학기 중에 미리 찾아보는 Windows 프로그램입니다.

- **받기**: [dist/app.exe](dist/app.exe) 를 내려받아 `최소성취수준 도우미.exe` 같은 이름으로 바꿔 실행합니다. 설치가 필요 없습니다.
- **사용 설명서**: [최소성취수준 도우미 사용 설명서.pdf](<최소성취수준 도우미 사용 설명서.pdf>) (7쪽)
- **입력**: 과목별 평가 항목과 반영비율, 학생의 수행·지필 점수, 결석 횟수. 학생은 **반·번호만** 적고 이름은 입력하지 않습니다.
- **결과**: 안전 / 주의 / 위험 / 미도달 단계와, 남은 평가에서 받아야 하는 득점률.
- **자료 보호**: 처음 실행할 때 만든 암호로 자료 파일 전체를 암호화합니다(AES-256, PBKDF2). 암호는 어디에도 저장하지 않으므로 잊으면 되찾을 수 없습니다.
- **업데이트**: 시작 화면이 이 저장소의 새 버전을 확인합니다. 내려받은 파일은 개발자 서명이 맞을 때만 설치됩니다.
- **문의**: 프로그램 안의 「개발자에게 문의」 버튼(카카오톡 오픈채팅).

판정은 참고용입니다. 실제 이수 여부는 학교의 학업성적관리규정과 교육청 지침에 따릅니다.

## 직접 빌드

Windows 에 들어 있는 C# 컴파일러만 씁니다. 명령은 `App.cs` 맨 위 주석에 있습니다. `--selftest 결과.txt` 로 자체 점검을 돌릴 수 있습니다.
